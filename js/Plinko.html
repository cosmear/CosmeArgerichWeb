Plinko

Arrastra el mouse hacia la pelota roja, el juego no funciona con colisiones no con clicks ya que p5 no soporta eventos de mouse de esa manera.

P5 aparte de ser un gran libreria para cualquier cosa grafica es muy buena para el calculos fisicos con coliciones echas a mano como en este juego

El juego es un clon de Plinko, un juego de azar que se popularizó en el programa de televisión "The Price is Right".

El objetivo es hacer que la bola caiga en una ranura al final del tablero, donde se puede ganar una cierta cantidad de puntos, mientras mas al medio este tu pelota mas puntos, cuidado con los rectangulos que quitan puntos si los tocas.

Por mas que se use la libreria P5 hay muchos elementos de javascript involucrados en la logica del juego. se recorren ciclos for se utilica if se utiliza distintas function para dibujar las distintas escenas y obiamente todos los operadores de metamatica t de comparacion.
